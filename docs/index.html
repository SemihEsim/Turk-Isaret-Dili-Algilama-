Projeyi Çalıştırın

Tüm modelleri kendi bilgisayarınızda deneyebilirsiniz

# 1. Repoyu klonla
git clone https://github.com/SemihEsim/Turk-Isaret-Dili-Algilama-.git
cd Turk-Isaret-Dili-Algilama-/TID

# 2. Gerekli paketleri yükle
pip install opencv-python mediapipe tensorflow scikit-learn

# 3. Random Forest (Harf Tanıma) çalıştır
cd random_forest
python realtime.py

# 4. 1D CNN (Kelime Tanıma) çalıştır
cd "../1d cnn"
python 1d_cnn.py
